# Derived checkpoints

These compact CSVs document the numerical state used for the 2026 analysis. They are checkpoints for later clean-machine tests, not substitutes for the raw inputs. No raw raster, shapefile, survey microdata, or Overleaf output is included.

- `chirps_2026_municipality.csv`: final May--August 2026 municipal CHIRPS measures.
- `chirps_historical_comparison_2015_2019_2026_municipality.csv`: historical comparison series.
- `chirps_*common_reference*.csv`: common-reference department/municipality z-score inputs.
- `maga_uso_tierra_2025_*_metrics.csv`: municipality and department employment/land metrics.
- `municipal_agricultural_drought_impact_2026_2015.csv`: current and 2015 descriptive impact-index components.
