The 2026 shock was spatially uneven.

The agricultural-worker-weighted curve places more mass below the extreme threshold than the unweighted municipal distribution. The distinction separates territorial incidence from workforce exposure.

16 / 22extreme-drought departments in both products

CHIRPS places 54.6% of agricultural workers in extreme-drought departments; ERA5-Land places 60.1%. The products remain separate because their records, grids, and reference distributions differ.

Figure 4. Guatemala. Drought, agricultural employment, poverty, and department prioritization.

Note. Panel a maps municipal CHIRPS Primera anomalies. Panels b–d use departments. Agricultural fill is the share of occupied workers in agriculture; proportional circles show worker counts. Poverty is ENCOVI 2023. Priority uses the balanced index reported in Appendix Table A3.

Figure PDF Full PNG Department data

Hazard, exposure, and poverty are related but distinct.

The four panels keep municipal rainfall severity separate from department agricultural structure and poverty. The prioritization score is a transparent relative index—not a probability of loss or an impact estimate.

Methods and scope

Publication figures backed by downloadable analytical checkpoints.

The public repository contains aggregate processed data and a self-contained Python figure builder. Raw rasters, household records, and restricted source files are not redistributed.
